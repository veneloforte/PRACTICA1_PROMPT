# Guía del proyecto

## Estructura

- data/raw: archivos originales
- data/processed: datos limpios o transformados
- notebooks: exploraciones y análisis
- src: código fuente
- docs: documentación

## Uso

1. Coloca los archivos nuevos en data/raw.
2. Crea notebooks o scripts en src.
3. Guarda resultados finales en data/processed.
4. Documenta hallazgos en docs.
